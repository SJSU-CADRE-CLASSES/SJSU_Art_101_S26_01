# Navigation Console

A purely tactile navigation interface. No visual information — only boxes that act as the navigation apparatus. All feedback is audio.

## Concept

For hominids who evolved in the deep sea without sight. The console is concerned solely with **navigation of surroundings**, not venturing upward.

- **9 boxes** in a 3×3 grid — directional navigation (N, S, E, W, NE, NW, SE, SW, center)
- Each box has a distinct tone when activated
- Cyclical drift so the interface is easier to sense
- Keyboard: arrow keys or number pad (1–9) to trigger corresponding boxes

## Controls

| Input | Box |
|-------|-----|
| `↑` `↓` `←` `→` | North, South, West, East |
| `7` `8` `9` | NW, N, NE |
| `4` `5` `6` | W, center, E |
| `1` `2` `3` | SW, S, SE |

## Run

Open `index.html` in a browser. Click anywhere first if needed for audio.
