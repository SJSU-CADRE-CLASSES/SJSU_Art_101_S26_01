# Legacy static shader demo (pre–Next.js)

The Three.js player used to be opened as a plain HTML file. The app now runs on **Next.js** (`npm run dev` from the repo root).

To preview this old entry locally, open **`legacy/index.html`** with **Live Server** or any static server from the **repository root** (so `../src` and `../style.css` resolve). Do not rely on this for production.

The main product is **`npm run dev`** → [http://localhost:3000](http://localhost:3000).
